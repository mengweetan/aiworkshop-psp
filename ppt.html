AI Introduction & Governance

Harish · 20 minutes

What AI Actually Is

Three layers of the modern AI stack:

LayerFunctionExamples
Foundation ModelsPattern recognition, generationGPT-4, Kimi, Gemini, Claude
Agent FrameworksOrchestration — AI → tools, data, APIsOpenClaw, LangChain, n8n
Business ApplicationsYour workflowCustom solutions, SaaS platforms
Key distinction: Generative AI creates content. Agentic AI executes tasks.

The 4 Types of AI Tools

Not all AI is the same. Understanding the categories helps you pick the right tool for the job:

TypeWhat It DoesExamplesBest For
i. Generative AICreates new content — text, images, audio, videoDola, OpenArt, ChatGPT, and many moreDrafting, brainstorming, content creation
ii. Coding AIWrites, completes, and refactors codeCodex, ClaudeSoftware development, automation scripts
iii. Web-based AIBrowser-native assistants that read, research, summarizeClaude.ai, Comet, NotebookLMResearch, document Q&A, knowledge work
iv. Agentic AIAutonomously executes multi-step tasks using tools and dataOpenClaw, Hermes Agent, DeerFlowWorkflow automation, end-to-end processes
Rule of thumb: Generative AI creates, Coding AI builds, Web-based AI researches, Agentic AI does. Today's workshop focuses primarily on Agentic AI — the category with the highest leverage for PSP workflows.

AI Governance Framework

Core Principles

  1. Data sovereignty — Where does your data go? Who controls it?
  2. Transparency — Can you audit AI actions and decisions?
  3. Accountability — Who's responsible when AI makes mistakes?
  4. Privacy compliance — PDPA requirements for SG organizations
  5. Human oversight — Critical checkpoints for high-stakes decisions

Risk and Deployment Model

MengWee · 15 minutes

Risk Assessment Framework

Risk Matrix for AI Deployment:

Impact LevelLow RiskMedium RiskHigh RiskCritical Risk
ExamplesMeeting summaries, draft emailsData analysis, report generationCustomer-facing comms, financial recordsLegal compliance, medical decisions
Human ReviewSpot-checkReview before useApprove every outputMultiple approvals + audit
RolloutImmediatePilot with 2-3 usersStaged with metricsExtended pilot + compliance review

Deployment Models

Option 1: Cloud SaaS

✅ Fast setup · ✅ Low upfront cost · ⚠️ Data leaves your control · ⚠️ Subscription per user

Best for: Small teams, low-sensitivity data, quick pilots.

Option 2: On-Premise

✅ Full data control · ✅ PDPA-friendly · ✅ Customizable · ⚠️ Higher setup · ⚠️ Needs IT support

Best for: Medium-large orgs, sensitive data, regulatory requirements.

Option 3: Hybrid

✅ Sensitive data on-prem, models in cloud · ✅ Balanced control · ⚠️ More complex architecture

Best for: Organizations with mixed data sensitivity.

PSP-Specific Considerations

Data Sensitivity Zones

  • Public: Event details, general announcements → any AI model OK
  • Internal: Member lists, attendance records → private deployment preferred
  • Confidential: Financial data, personal member info → on-premise required
  • Restricted: Governance documents, personnel matters → human-only, AI-assisted summaries max

Recommended Approach

  1. Phase 1 (Month 1–2): Pilot with 3–5 staff on low-risk tasks
  2. Phase 2 (Month 3–4): Expand to medium-risk workflows
  3. Phase 3 (Month 5–6): Full deployment with governance + audit review

Success Metrics

  • Time saved per user per week
  • Error rate (AI mistakes requiring human correction)
  • User adoption rate
  • Task completion speed (before / after)
  • Security incidents (target: zero)

Case Studies

MengWee / Anthony · ZX · Teddy · 45 minutes total

5a. RE Brokering AI — MengWee / Anthony, 15 min

Client: Nejilock Technology

Segment: Property brokerage (40+ agents)

Problem Statement

  • Agents spent 60% time on admin, only 40% on revenue work
  • Manual process: inquiries → search portals → copy-paste → phone-tag scheduling → forgotten follow-ups
  • Lead-to-viewing conversion: 20%
  • Agent burnout from repetitive tasks

Workflow Transformation

Before (Manual)After (AI-Assisted)Time Saved
Search 3–5 portals, copy-paste 20–30 listingsAgent auto-searches, ranks by fit, sends top 1045 min → 5 min
Schedule viewings via calls/textsAgent coordinates with all parties, proposes slots30 min → 5 min
Manual follow-ups (often missed)Agent auto-follows up at day 3, 7, 1420 min → 0 min
Status updates to managerAuto-logged in dashboard15 min → 0 min

Results (After 3 Months)

Admin time

60% → 15% (freed 18h/week per agent)

Conversion

20% → 60% (3× improvement)

Viewings

3/week → 8/week per agent

ROI

Break-even at 4 months · Delivered in 12 weeks

Key Lesson: AI doesn't replace agents. It removes the friction that prevents them from closing deals. The brokerage invested in AI to amplify their agents, not cut headcount.

5c. Email Marketing AI — Teddy, 15 min

[Suggested outline — to be expanded by Teddy]

Problem Statement

  • Generic mass emails → low engagement
  • Manual segmentation time-consuming
  • A/B testing requires separate campaigns
  • Tracking opens/clicks across platforms
  • Writing compelling copy takes hours per campaign

Solution Components

  1. Audience segmentation agent — analyzes behavior, builds targeted lists
  2. Copy generation — drafts 3 variants per segment (formal / casual / promotional)
  3. Send-time optimization — best send-time per segment
  4. Performance monitoring — tracks opens, clicks, conversions in real-time
  5. Follow-up automation — re-engages non-openers with a different angle

Results

MetricBeforeAfter
Open rate22%38%
Click-through rate3.5%8.2%
Campaign prep time6 hours45 minutes
Revenue per campaign—+65%

Best Practices

  • Always include unsubscribe (PDPA compliance)
  • Human review before send (esp. sensitive topics)
  • Test with small segment first
  • Monitor spam score
  • Respect frequency caps (max 1/week for most audiences)

Deliverable: 1-page workflow map (current state → pain points → AI opportunity).

Part 2: Hands-On Demo (25 min)

Each group tests their workflow with OpenClaw. Station tasks:

  1. Text a real request to the agent (WhatsApp / Telegram)
  2. See it access your data (calendar, email, files — demo environment)
  3. Review the output
  4. Iterate the prompt ("make it more formal", "add deadline reminder")
  5. Check the audit log (what did the agent actually do?)

Example Tasks by Group
